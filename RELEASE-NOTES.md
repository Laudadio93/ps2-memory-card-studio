# PS1 & PS2 Memory Card Studio

This release combines the PS1 and PS2 memory-card tools in one portable Windows application. Extract the ZIP and run **PS1 and PS2 Memory Card Studio.exe**. Python and separate card tools are not required.

## New PS1 features

- Create blank 128 KiB PS1 cards or import multiple MCS saves and saves from raw PS1 cards.
- Export MCR, MCD, VM1, or VMC cards, with 15 usable save blocks.
- Validate directory frames, checksums, block chains, duplicate names, and card capacity.
- Use the dedicated PS1 card preview and output controls.
- Copy finished cards to /PS1/VMC/ for Apollo Save Tool.

## PS2 features

- Import and combine PSU, MAX, CBS, SPS, XPS, and PS2 PSV saves.
- Choose ECC or non-ECC and 8, 16, 32, or 64 MiB.
- Review capacity and duplicate-save errors, then export .ps2 or .vmc.
- Use the included blank templates and the selected-capacity card preview.
- Copy finished cards to /PS2/VMC/ for Apollo Save Tool.

## Application improvements

- Switch between the PS1 and PS2 views in one window.
- Choose and remember an output folder. Existing output cards are backed up before replacement.
- Work locally with bundled runtimes and templates.
- Includes the custom PlayStation memory-card Windows icon.
- The Windows ZIP includes upstream PS2 engine credits and license text.

The application was launched and both card views were selected during the release check. Console gameplay and compatibility depend on the target setup and individual saves. See the project README for input limitations and full credits.
